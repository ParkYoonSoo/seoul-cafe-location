# 서울 카페·베이커리 3년 뒤 입지 분석

투자금과 업종(카페 / 베이커리 / 베이커리 카페)·업태(테이크아웃 / 좌석형 / 대형·목적지형)를 고르면,
실제로 들어갈 수 있는 서울 상권만 남긴 뒤 3년 뒤 점포당 실질 매출이 가장 많이 오를 상권 Top 3를 고르고
출점 자리·시점, 컨셉·메뉴, 손익 시뮬레이션, 경쟁·프랜차이즈 체크까지 이어서 보여주는 웹 페이지입니다.

## 바로 보기

서버가 필요 없습니다. `site/index.html`을 브라우저로 열면 됩니다. 지도 배경과 차트 라이브러리를 불러오기 위해 인터넷 연결만 필요합니다.

## 분석 구조

| 단계 | 내용 |
|---|---|
| L1 제약 | 투자금·업종·업태로 필요 투자금, 임대료 비율(매출의 15% 이하), 예상 영업이익(흑자), 업태 적합성을 따져 들어갈 수 있는 상권만 남김 |
| L2 동인 | 수요 × 공급 × 비용, 현재 수준·최근 추세·미래 요인 3×3 동인으로 3년 뒤 점포당 실질 매출 성장을 예측 (릿지 회귀) |
| L3 검증 | 2022Q4 동인 → 2022Q4~2025Q4 실제 성장 백테스트, 업태 가중치 ±20% 민감도, 유동인구 교차 확인 |
| L4 결론 | Top 3, 상권별 근거(동인 기여도), 예상 반론과 대응 |
| L5 실행 | 선택한 상권의 출점 자리·시점, 인테리어·메뉴·마케팅, 손익 시뮬레이션, 경쟁 체크 |

점수 기준
- **성장형**: 3년 뒤 점포당 실질 매출 증가율 예측치로 순위
- **안정형**: 성장 예측 50% + 현재 업종 매출 규모 50%로 순위

## 데이터 다시 만들기

```bash
python3 collector/build.py          # data/raw 캐시로 site/data.js 재생성 (표준 라이브러리만 사용)
python3 collector/make_artifact.py  # claude.ai 공유 페이지용 site/artifact.html 생성
```

`data/raw/`에 수집 스냅샷이 들어 있어 인증키 없이 같은 결과를 재현할 수 있습니다.
새로 수집하려면 `data/raw/`의 해당 파일을 지우고 서울 열린데이터광장 인증키를 환경변수로 넣어 실행합니다.

```bash
SEOUL_API_KEY=발급받은키 python3 collector/build.py
```

## 폴더 구조

```
collector/build.py          수집 → 좌표 변환 → 동인 계산 → 백테스트 → 예측 → site/data.js
collector/prefetch.py       일부 데이터를 별도 프로세스로 미리 받는 보조 스크립트
collector/make_artifact.py  index.html → artifact.html 변환
data/raw/                   API 수집 스냅샷 (필터링된 행만 저장)
site/index.html, app.js     웹 페이지
site/data.js                분석 결과 (자동 생성)
site/gu.js                  서울 자치구 경계
```

## 한계

- 자치구별 임대료, 권리금, 인테리어·설비비, 인건비, 업태별 매출 배수는 출처가 없는 가정치입니다. 손익 시뮬레이터에서 바꿀 수 있습니다.
- 베이커리 예측력은 약합니다 (검증용 순위상관 0.14). 카페·베이커리 카페는 0.24 수준입니다.
- 프랜차이즈는 상호명 패턴으로 분류해 일부 누락·오분류가 있을 수 있습니다.
- 신규 역·입주 같은 미래 요인과 임대료 추세는 공공 데이터가 없어 점수에서 빠져 있습니다.
